# GitHub Workflow (No Overlap)

1. One branch per story: `feature/us-xx-short-name`.
2. Edit only owned folders.
3. Contract changes in separate PR first.
4. Keep PRs small and story-scoped.
5. Merge dependency order:
   - Aditya (US-01..07) -> Samatham (US-08..15) -> Khushi (US-16..25)
6. Rebase frequently and resolve conflicts immediately.
